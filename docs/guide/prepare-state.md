# Prepare State

A prepare script's `state` is generated as typed exports and importable from `#nuxt-prepare`.

::: tip
Similar to Nuxt 2's `nuxtServerInit`, but runs at build time and generates type-safe imports.
:::

## Return State From a Script

This script fetches one todo item and returns it as state:

::: code-group
```ts [server.prepare.ts]
import { defineNuxtPrepareHandler } from 'nuxt-prepare/config'
import { ofetch } from 'ofetch'

export default defineNuxtPrepareHandler(async () => {
  const todoItem = await ofetch('https://jsonplaceholder.typicode.com/todos/1')

  return {
    state: {
      todoItem
    }
  }
})
```
:::

## Import It From `#nuxt-prepare`

State from all prepare scripts is merged – [a later script wins](/guide/prepare-scripts#a-script-s-result-wins-over-nuxt-config-ts) where two set the same key – and the module generates two files from it in `.nuxt/module/`:

**`nuxt-prepare.mjs`** – Exported state values:

<!-- eslint-skip -->

```ts
// Generated by nuxt-prepare
export const todoItem = {
  "userId": 1,
  "id": 1,
  "title": "delectus aut autem",
  "completed": false
}
```

**`nuxt-prepare.d.ts`** – Type definitions:

<!-- eslint-skip -->

```ts
// Generated by nuxt-prepare
export declare const todoItem: {
  "userId": 1,
  "id": 1,
  "title": "delectus aut autem",
  "completed": false
}
export type TodoItem = typeof todoItem
```

Both files are written by serializing the state, so the declaration carries the literal values rather than widened ones – `todoItem.id` is `1`, not `number`.

Import it from `#nuxt-prepare` anywhere:

```ts
// In any component, composable, page, layout, or plugin
import { todoItem } from '#nuxt-prepare'

const todos = ref([todoItem])
```

```ts
// In Nitro server routes and middleware
import { todoItem } from '#nuxt-prepare'

export default defineEventHandler(() => {
  return { todo: todoItem }
})
```

## What Survives Serialization

State values are JSON-serialized during code generation. This means:

- ✅ Objects, arrays, strings, numbers, booleans
- ❌ Functions, classes, symbols, `undefined`

```
// ✅ This works
state: {
  config: { api: 'https://api.example.com' },
  items: [1, 2, 3]
}

// ❌ This doesn't work
state: {
  handler: () => console.log('hello'), // Functions are lost
  data: undefined, // The key is dropped entirely
  fallback: null // So is this
}
```

## Populate a Pinia Store

Import the prefetched data in your [Pinia](https://pinia.vuejs.org) store:

::: code-group
```ts [stores/todo.ts]
import { defineStore } from 'pinia'
import { todoItem } from '#nuxt-prepare'

export const useTodos = defineStore('todos', {
  state: () => ({
    todos: [todoItem]
  })
})
```
:::
